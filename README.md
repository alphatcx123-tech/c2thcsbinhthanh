# 🌐 Website THCS Bình Thành

Website giới thiệu và cung cấp thông tin cho trường THCS Bình Thành.

## 📌 Giới thiệu

Dự án xây dựng một website hiện đại giúp học sinh, phụ huynh và giáo viên dễ dàng xem thông tin của trường.

## ✨ Tính năng

- 🏫 Giới thiệu về nhà trường
- 📰 Hiển thị tin tức, sự kiện
- 🔍 Tìm kiếm nội dung nhanh
- ⏰ Đồng hồ thời gian thực
- 👥 Bộ đếm lượt truy cập
- 📚 Tài nguyên học tập cho học sinh lớp 6 - 9
- 📱 Giao diện tương thích điện thoại và máy tính

## 🛠 Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- Vercel (Hosting)
- GitHub (Quản lý mã nguồn)
